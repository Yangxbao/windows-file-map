# Windows 文件地图与中文目录管理助手

> 只读、离线、带中文解释的本机文件全量盘点工具。
> 它把整台 Windows 电脑的文件系统扫进一个本地 SQLite 数据库，再用中文网页分页浏览、
> 搜索、识别开发项目、分析空间占用——**全程不修改、不移动、不删除任何原始文件。**

## 这是什么

你是否遇到过这些问题：

- 不知道很多文件夹是干什么用的；
- 目录都是英文名，时间久了忘记含义；
- 不清楚自己写过的项目存放在哪里、哪些是源代码、哪些是编译产物；
- 不知道哪些目录能清理、哪些是系统必需的；
- 想要一个简单的中文页面随时查看整台电脑的文件布局。

这个工具就是为这些问题准备的：**先让你"看懂"整台电脑，再决定要不要整理。**

## 功能特性

- **全量递归盘点**：所有本地固定磁盘逐级枚举到最深一层，无条目数 / 深度 / 总量上限；
  系统目录（Windows、Program Files、ProgramData）、`node_modules`、`.git`、`target`、
  `build`、`dist` 等大型目录同样保留完整目录树与文件清单（只读元数据，不读文件内容）。
- **SQLite 存储 + 服务端分页**：数百万条目流畅浏览，前端只加载当前页。
- **中文解释层**：内置常见目录/文件知识库（`node_modules` → “Node.js 依赖包目录”等），
  结合路径、名称、内容类型与项目标识文件给出用途解释与置信度，判断不了的诚实标注"待确认"。
- **项目识别**：依据 `pom.xml` / `package.json` / `go.mod` / `Cargo.toml` / `*.sln` / `.git` /
  README 等识别 Java、Spring Boot、Vue、React、Node.js、Python、Go、Rust、.NET 等项目，
  记录入口文件、配置、源码/文档/依赖目录与识别依据（绝不运行项目代码）。
- **错误分类与定向重试**：区分 拒绝访问 / 对象丢失 / 被占用 / 路径超长 / 链接目标读取失败；
  被占用类自动重试；支持管理员权限对历史失败目录做**只读**定向重试。
- **断点续扫与增量扫描**：分批提交，中断不丢数据；`--resume` 从断点继续；
  `--incremental` 按目录修改时间只重扫变化部分。
- **大小实测聚合**：目录大小自底向上逐级汇总；子树内存在无法访问部分时标记"大小不完整"，
  数值为已确认部分的下限，不冒充完整值。
- **网页五页视图**：电脑总览 / 目录树 / 项目地图 / 全局搜索 / 空间与风险；
  支持复制真实路径、调用资源管理器打开所在文件夹（本地服务模式）。
- **报告导出**：全量清单 CSV 分卷（每卷 100 万行）、扫描范围与遗漏、项目识别报告、
  整理建议（只建议，不执行）。

## 快速开始

环境要求：Windows 10/11，Python 3.8+（仅标准库，无需安装任何依赖）。

```bat
:: 1. 全量扫描（只读，首次约几分钟，视文件数量而定）
fm_scan.py

:: 2. 打开中文地图（启动本地服务并自动打开浏览器）
启动文件地图.bat
```

| 命令 | 用途 |
|---|---|
| `python fm_scan.py` | 全量扫描（重建数据库） |
| `python fm_scan.py --resume` | 续扫上次中断的扫描 |
| `python fm_scan.py --incremental` | 增量扫描（跳过未变化目录） |
| `python fm_scan.py --admin-retry` | 管理员终端运行：定向重试历史"拒绝访问"目录（只读） |
| `python fm_scan.py --recompute` | 仅重算大小统计并重新生成报告 |
| `python fm_report.py` | 单独重新生成报告 |
| `python serve.py` | 启动本地网页服务（127.0.0.1:8618） |

## 安全承诺（重要）

- **只读**：不重命名、移动、删除、覆盖任何被扫描文件；不在被扫描目录写入任何文件；
  所有输出只保存在工具自身目录。
- **不读文件正文**：仅读取 `package.json`、`pom.xml`、`README` 等小型标识文件的开头片段用于项目识别。
- **敏感文件零接触**：`.env`、密钥、证书、凭证类文件只记录路径与类型，绝不读取内容；
  私人照片/视频/文档仅按名称、类型、大小、时间归类。
- **链接安全**：符号链接与目录联接记录目标但不跟随，防止循环引用与重复统计。
- **不提权、不改配置**：绝不使用 takeown/icacls/注册表/安全防护关闭等手段；管理员模式只做
  只读重试，且需要你通过 Windows UAC 亲自确认。
- **完全离线**：不联网、不上传、不登录；生成的 `fmdata.db` 含本机完整文件清单，
  属于个人数据，请勿分享。

## 架构

```
fm_scan.py   只读扫描引擎：递归枚举 + 错误分类 + 项目识别 → fmdata.db (SQLite, WAL)
fm_kb.py     共享知识库：目录/文件中文名映射、项目标识规则
fm_report.py 报告生成：全量 CSV 分卷、扫描范围与遗漏、项目识别、整理建议
serve.py     本地服务：静态页面 + 分页 API（children/node/search/projects/risk/open）
index.html   中文单页应用：总览/目录树/项目地图/搜索/空间与风险
```

## 已知边界

- 回收站内容、系统还原点/卷影副本、本工具自身目录**按明确规则排除**并逐条记录；
- 受 Windows 强保护的目录（如 `System32\config`、其他用户注册表、WindowsApps）即使管理员
  权限也可能无法枚举，工具会保留失败记录，绝不假装扫描完成；
- 个别文件名含 Windows 无法编码的字符，展示时以 `?` 代替，真实文件不受影响。
